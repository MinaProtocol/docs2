# Mina zkApp: Oracle Example

A Mina smart contract that verifies the authenticity of a signed API response (generated by the code in the [oracle](../oracle/) directory) then emits an event with the user's id if their credit score is 700 or higher. It was created for [Tutorial 7: Oracles](https://docs.minaprotocol.com/zkapps/tutorials/oracle).

This template uses TypeScript.

## How to build

```sh
npm run build
```

## How to run tests

```sh
npm run test
npm run testw # watch mode
```

## How to run coverage

```sh
npm run coverage
```
