Find any sequence of snark work between two indexes in all available snark work. Returns both completed and uncompleted work.


```graphql
snarkWorkRange(
  endingIndex: UInt32
  startingIndex: UInt32!
): [PendingSnarkWorkSpec!]!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>snarkWorkRange.<b>endingIndex</b></code>](#ending-index)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>UInt32</b></code>](/node-developers/graphql-api/reference/types/scalars/uint-32.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#ending-index\} 
The last index to be taken from all available snark work (exclusive). If not specified or greater than the available snark work list,all elements from index [startingIndex] will be returned. An empty list will be returned if startingIndex is not a valid index or if startingIndex &#x003E;= endingIndex.


#### [<code style={{ fontWeight: 'normal' }}>snarkWorkRange.<b>startingIndex</b></code>](#starting-index)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>UInt32!</b></code>](/node-developers/graphql-api/reference/types/scalars/uint-32.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#starting-index\} 
The first index to be taken from all available snark work
