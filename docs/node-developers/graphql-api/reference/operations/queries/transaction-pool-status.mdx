Occupancy of this daemon's transaction pool, and the fee a new command must beat once the pool is full. Cheap enough to poll before each submission, as a back-pressure signal


```graphql
transactionPoolStatus: TransactionPoolStatus!
```


### Type

#### [<code style={{ fontWeight: 'normal' }}><b>TransactionPoolStatus</b></code>](/node-developers/graphql-api/reference/types/objects/transaction-pool-status.mdx) <Badge class="badge badge--secondary " text="object"/> 
Occupancy of the transaction pool. When the pool is full, admitting a new command evicts the command with the lowest fee per weight unit, together with every later-nonce command from the same fee payer
