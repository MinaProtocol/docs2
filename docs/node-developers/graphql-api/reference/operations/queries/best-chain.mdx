Retrieve a list of blocks from transition frontier's root to the current best tip. Returns an error if the system is bootstrapping.


```graphql
bestChain(
  maxLength: Int
): [Block!]
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>bestChain.<b>maxLength</b></code>](#max-length)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/node-developers/graphql-api/reference/types/scalars/int.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#max-length\} 
The maximum number of blocks to return. If there are more blocks in the transition frontier from root to tip, the maxLength blocks closest to the best tip will be returned
