Find all the actions associated to an account from the current best tip.


```graphql
accountActions(
  maxLength: Int
  publicKey: PublicKey!
  token: TokenId
): [ActionState!]!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>accountActions.<b>maxLength</b></code>](#max-length)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/node-developers/graphql-api/reference/types/scalars/int.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#max-length\} 
The maximum number of blocks to search for actions. If there are more blocks in the transition frontier from root to tip, the maxLength blocks closest to the best tip will be returned

Public key of account being retrieved


#### [<code style={{ fontWeight: 'normal' }}>accountActions.<b>token</b></code>](#token)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>TokenId</b></code>](/node-developers/graphql-api/reference/types/scalars/token-id.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#token\} 
Token of account being retrieved (defaults to MINA)
