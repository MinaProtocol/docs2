Occupancy of the transaction pool. When the pool is full, admitting a new command evicts the command with the lowest fee per weight unit, together with every later-nonce command from the same fee payer


```graphql
type TransactionPoolStatus {
  maxSize: Int!
  minimumFeePerWeightUnit: String
  size: Int!
}
```

The lowest fee per weight unit of any command in the pool, in nanomina, as a decimal integer or a fraction 'n/d'. Null if the pool is empty. Once the pool is full, a new command must pay strictly more than this to be admitted. Payments and stake delegations have weight 1
