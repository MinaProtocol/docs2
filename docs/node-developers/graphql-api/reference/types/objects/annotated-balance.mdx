A total balance annotated with the amount that is currently unknown with the invariant unknown &#x003C;= total, as well as the currently liquid and locked balances.


```graphql
type AnnotatedBalance {
  blockHeight: Length!
  liquid: Balance
  locked: Balance
  stateHash: StateHash
  total: Balance!
  unknown: Balance!
}
```
