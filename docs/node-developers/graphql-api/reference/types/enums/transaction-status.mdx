Status of a transaction


```graphql
enum TransactionStatus {
  INCLUDED
  PENDING
  UNKNOWN
}
```


### Values

#### [<code style={{ fontWeight: 'normal' }}>TransactionStatus.<b>INCLUDED</b></code>](#included) \{#included\} 
A transaction that is on the longest chain


#### [<code style={{ fontWeight: 'normal' }}>TransactionStatus.<b>PENDING</b></code>](#pending) \{#pending\} 
A transaction either in the transition frontier or in transaction pool but is not on the longest chain


#### [<code style={{ fontWeight: 'normal' }}>TransactionStatus.<b>UNKNOWN</b></code>](#unknown) \{#unknown\} 
The transaction has either been snarked, reached finality through consensus or has been dropped
