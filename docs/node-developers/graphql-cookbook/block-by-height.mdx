# Block by height

**What this does:** fetches one block by height, with its producer, time, coinbase, and the hashes of its transactions.

**When to use it:** in an explorer, an indexer, or any time you need a block older than the daemon's last 290.

## Query

Send to the [Archive Node API](/node-operators/data-and-history/archive-node-api), for example `https://devnet-archive-node-api.gcp.o1test.net`.

```graphql
query BlockByHeight($from: Int!, $to: Int!) {
  blocks(
    query: { blockHeight_gte: $from, blockHeight_lt: $to, canonical: true }
    limit: 1
  ) {
    blockHeight
    stateHash
    parentHash
    creator
    dateTime
    transactions {
      coinbase
      userCommands {
        hash
      }
      zkappCommands {
        hash
      }
    }
  }
}
```

## Variables

To get block 594442, ask for the range from 594442 up to, but not including, 594443:

```json
{ "from": 594442, "to": 594443 }
```

## Notes

- `blockHeight_gte` is inclusive and `blockHeight_lt` is exclusive. Widen the range and raise `limit` to page through blocks, and use `sortBy: BLOCKHEIGHT_DESC` to get the newest first.
- `canonical: true` returns only finalized blocks, about `k` (290) blocks behind the tip. Recent blocks are not canonical yet. Drop the filter, or use `inBestChain: true`, to include them.
- The daemon's `block(height: …)` query only answers for blocks in its transition frontier. For an older height, it returns `Could not find block in transition frontier with height …`.
- `coinbase` is in nanomina.
